# E-Commerce Backend API
Node.js + Express.js + SQLite (better-sqlite3) mini project.

    npm install
    npm start        # http://localhost:3000/api/health
    npm run seed     # optional sample products
    npm run demo     # (second terminal) prints a 23-step request/response walkthrough
    npm test         # 18 automated tests

Endpoints: GET /api/health, GET|POST /api/products, GET|PUT|DELETE /api/products/:id,
GET|POST /api/orders, GET /api/orders/:id. See the project report for details.
